# Source Index

Every file in `sources/` is listed here. Files are kept exactly as received. If a file needs converting or extracting, the derived copy goes next to the original with a suffix that says what was done (for example `manual.pdf` and `manual.extracted.txt`).

The IDs (`S001`, `S002`, …) are used for citations in `docs/`, for example `[S003]`.
