## Conventions

- Cite sources by ID from [`../sources/INDEX.md`](../sources/INDEX.md), for example `[S001]`.
- Mark anything not yet confirmed by a source as **(unverified)**.
- When two sources disagree, record both, each with its citation.
- Give addresses and register values in hex with a `$` prefix (`$FFFF8200`), following Atari convention.
